# Cortex Bridge 0.6.5 — unfinished preview

Publication requested explicitly before completion. Tag: v0.6.5-preview.1.
This is an inspectable development snapshot, not a stable release or a claim
that all tests, installation paths or provider requirements have passed.

- Codex-operator / ChatGPT-planner supervision contract and installable harness.
- Bounded file inventory, artifact manifests and source freshness checks.
- Durable outbound reservation, explicit delivery reconciliation and no silent retry.

- Acceptance evidence linked to actual recorded results, not model declarations.
