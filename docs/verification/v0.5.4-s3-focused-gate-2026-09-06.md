## Launcher defect fixed

The double-click launcher previously masked the storage guard exit status and
ignored explicit diagnostic arguments. It now:

- dispatches `doctor --json` and other explicit commands without starting;
- preserves the exact startup exit code;
- explains that `STORAGE_VOLUME_MISSING` means the configured encrypted volume
  is absent or not visible;
- exposes the same state through an `external_storage` doctor check.
