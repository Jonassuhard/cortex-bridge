## Bugs found and fixed during this pass

1. **`bf42766` — unconfirmed model switch on the default transport.** The MV3
   `select_model` returned success unconditionally after a click; the console
   then reported `confirmed: true` even when ChatGPT ignored the click or
   Radix re-rendered the switcher (same failure class as the historical
   stale-node bug). Fix: fail-closed confirmation polling a freshly
   reacquired trigger (5 s bound), `MODEL_CONFIRM_FAILED` otherwise. 3
   regression tests.
2. **`551e433` — dual-writer open timeout on real Chrome.** Two concurrent
   new-chat writers: tab allocation serializes inside the extension, so the
   queued writer's 10 s command deadline expired while waiting
   (`SELECTION_FAILED` / `EXTENSION_TIMEOUT`). Fix: bounded 30 s budget for a
   session's first navigation; switches keep the strict 10 s contract. 1
   regression test; validated live in run #4 immediately after.
