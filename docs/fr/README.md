# Cortex Bridge — Guides en français

Quatre petits guides, dans l'ordre de la vie du produit :

1. **[Démarrage](DEMARRAGE.md)** — télécharger, installer, lancer la première fois.
2. **[Utilisation](UTILISATION.md)** — connecter ChatGPT, lancer une mission, approuver, lire le rapport.
3. **[Mise à jour](MISE-A-JOUR.md)** — une commande, puis deux gestes.
4. **[Dépannage](DEPANNAGE.md)** — « qu'est-ce qu'il manque ? » : chaque symptôme, sa cause, sa solution.

À tout moment, une seule commande te dit ce qui manque et comment le réparer :

```bash
scripts/cortex.sh doctor
```
