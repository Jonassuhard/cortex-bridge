## Comparison design

Arm A: executor alone. Arm B: ChatGPT brain + the same executor via Cortex.
Hold initial bytes, executor identity/reasoning/tools, task brief and acceptance
constant. Clean context and workspace per arm. Counterbalance run order.
Three paired trials per task for a preliminary comparison; fewer are a pilot.
If only the current Codex model is available, label it explicitly; do not call
it a small-model benchmark. Freebuff may be used only with identity verified.

Per-run maximum: task A 20 minutes / 30 local actions; task B 45 minutes /
60 local actions. Both arms get the same wall-time/action budget. Brain calls
consume wall time; report their count and latency separately. Stop is a result,
not permission to quietly extend one arm's budget. Predeclare trial-specific
fixture seeds and equal change-request timing. Hidden test answers never enter
the contestant prompt. Evaluator repairs invalidate autonomous-success claims.

Report each acceptance criterion as pass/fail, plus end-to-end success (all
mandatory criteria), time to first working result, total time, local actions,
brain rounds, bytes transferred, retries, regressions and human interventions.
Token/cost/quota values are unavailable unless directly measured; never infer
tokens from character count. Success rate = successful valid runs / valid runs;
show numerator/denominator and every invalid/aborted trial separately.
Report paired time differences only alongside success outcomes. No weighted
global score or claim of Astra equivalence. Small samples are exploratory.
